# v1.0.3 — SQLs por capítulo

Baixe **atlas-leitor-v1.0.3.zip**, extraia e siga `sql/capitulos/README.md`.

- 68 arquivos SQL numerados para os laboratórios dos capítulos 2 a 14.
- Guia por capítulo com tabelas a importar, preparação, ordem, conferências e retomada da sessão.
- Texto acessível pelo botão Raw na página pública: copie e cole no Editor de SQL do Databricks, sem instalar editor.
- No capítulo 13, referência, duplicação, ausência e restauração têm conferências separadas. Não execute o roteiro inteiro de uma vez.
- Exemplos empresariais e fragmentos incompletos são listados como excluídos; não exigem criar tabelas inexistentes no pacote.
- Manifesto SQL registra a correspondência de cada arquivo com o bloco do livro.

O conteúdo e a profundidade do livro permanecem preservados. A leitura sem computador não exige download.
O dataset continua Atlas 1.0: os 14 CSVs e seu manifesto original não foram alterados.
O ZIP preserva os hashes oficiais e possui empacotamento reproduzível. Os validadores editoriais
não fazem parte do percurso do leitor e não comprovam execução real no Databricks.
