# v1.0.2 — pacote do leitor com identidade verificável

Baixe **atlas-leitor-v1.0.2.zip** nesta página e extraia pelo sistema operacional.
Os 14 CSVs prontos estão em `data`. Comece por `pedidos.csv`, seguindo o capítulo 2 e o Apêndice A.

Esta versão mantém as melhorias de documentação e Databricks SQL de v1.0.1 e acrescenta um pacote
do leitor sem geradores ou notebooks históricos. Os 14 CSVs desse pacote correspondem byte a byte
aos hashes do manifesto original Atlas 1.0. Nenhum valor, contagem ou regra do caso foi alterado.

Os arquivos automáticos **Source code** do GitHub normalizam quebras de linha; não são o pacote
recomendado para a prática. A diferença foi identificada pela nova conferência do download real.
O empacotador editorial torna explícita a convenção original CRLF, sem regenerar dados.

A leitura do livro continua independente de conta, download ou execução. Para reproduzir, basta
importar os CSVs e usar SQL no Databricks; não é necessário instalar programas externos.
