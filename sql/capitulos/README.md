# SQL por capítulo

Arquivos opcionais para praticar Dos Dados à Decisão no Databricks, sem transcrever o SQL do exemplar impresso. A leitura do livro continua completa sem baixar ou executar estes arquivos.

## Antes de começar

Use os CSVs oficiais e siga a importação do capítulo 2 e do Apêndice A. Não execute programas de geração ou manutenção. Comece somente por pedidos; importe os demais arquivos antes dos capítulos que os utilizam.

1. Abra abaixo a pasta do capítulo e leia seu README antes de copiar SQL.
2. Na página pública do Atlas, abra o arquivo numerado e use Raw para ver somente o texto. Copie o conteúdo e cole no Editor de SQL do Databricks. Não é necessário instalar editor ou importar notebooks.
3. Substitua todo o par atlas_lab.dados pelo catálogo/esquema autorizado da sua conta, como atlas.livro, sem mudar o nome final da tabela.
4. Use uma consulta exclusiva para o capítulo e o mesmo warehouse. Execute os arquivos na ordem do README, conferindo um resultado antes do próximo. Não execute todas as pastas de uma vez.
5. Se perder a sessão, reexecute a preparação e as visões derivadas anteriores ao ponto de retomada. Salvar o texto não torna visões temporárias permanentes.

Os arquivos SQL preservam os blocos reproduzíveis do livro. Não incluem as tabelas empresariais Bronze/Silver/Gold, fragmentos incompletos ou a automação de produção. Esses exemplos continuam explicados no livro; sua ausência aqui não é erro na importação.

O capítulo 1 não contém laboratório SQL. Nos capítulos 12 e 14, os arquivos não substituem as atividades de desenho operacional e interpretação. O capítulo 13 tem etapas repetidas de conferência: execute somente o arquivo indicado em cada estado, nunca Executar tudo sobre o roteiro completo.
